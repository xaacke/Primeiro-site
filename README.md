# Estrutura de Branches (GitFlow)

Este repositório segue o modelo **GitFlow** de gerenciamento de configuração:

| Branch | Finalidade |
|--------|-----------|
| `main` | Código estável. Contém o sistema legado original e, ao final, o sistema modernizado |
| `develop` | Branch de integração. Todo o trabalho do trio passa por aqui antes de ir ao `main` |
| `feature/*` | Branches individuais para cada funcionalidade nova |

## Como acessar o sistema legado original

O estado original do site (antes da reengenharia) está preservado pela tag `v0.0-legado`.

**Via navegador (GitHub):**
Acesse a aba **Tags** do repositório e selecione `v0.0-legado`.

**Via terminal (Git):**
```bash
git checkout v0.0-legado
```

Para voltar ao estado atual:
```bash
git checkout develop
```
